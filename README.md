# Conector de artículos por temática con línea de tiempo

Pequeña aplicación web en HTML/CSS/JS que permite:

- Seleccionar un artículo base.
- Encontrar artículos relacionados por temas en común.
- Ver los resultados ordenados cronológicamente en una línea de tiempo.

## Ejecutar localmente

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000`.
